# 🌿 Personalized Wellness Prediction System

This is a Streamlit-powered web app that generates synthetic wellness data and provides personalized predictions and recommendations for:

- Nutrition plans 🍎  
- Workout routines 💪  
- Sleep improvements 😴  
- Overall wellness enhancement 🧘

## 🚀 Features

- AI-powered recommendation engine
- Beautiful UI with visual comparisons
- Data generation using realistic health patterns
- Machine learning with Random Forest models
- Streamlit-based interactive app

## 🧰 Tech Stack

- Python 🐍
- Streamlit
- scikit-learn
- pandas, numpy
- matplotlib, seaborn

## 🛠️ How to Run Locally

```bash
git clone https://github.com/your-username/wellness-predictor.git
cd wellness-predictor
pip install -r requirements.txt
streamlit run main.py
```

## 🌐 Deployment on Streamlit Cloud

1. Fork or upload this project to your GitHub account.
2. Go to [Streamlit Cloud](https://streamlit.io/cloud).
3. Click **“New app”**.
4. Select your repo and set `main.py` as the entry point.
5. Deploy!

## 🙏 Disclaimer

This tool provides **AI-generated suggestions** and should not be used as medical advice. Please consult a licensed health professional before making lifestyle changes.
